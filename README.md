# SmartThings LAN Edge Drivers

Custom SmartThings LAN Edge Drivers for a few devices with no official
SmartThings support — all controlled entirely over the local network, no
cloud dependency once set up.

- **[skyfan-driver](skyfan-driver/)** — Ventair Skyfan DC ceiling fans,
  over Tuya's local LAN protocol.
- **[se-modbus-driver](se-modbus-driver/)** — SolarEdge inverter, over
  local Modbus TCP (SunSpec).
- **[bigassfans-driver](bigassfans-driver/)** — Big Ass Fans Haiku H/I
  Series ceiling fans, over their local "i6" protocol, mDNS
  auto-discovered.

Each has its own `README.md` (technical details, setup).
